# Basic-Calculator

How to use?
- Install Node.js
- Clone the Repository
- Open the Project Directory
- Install Dependencies (npm install)
- Start the Application (npm start)

Information
This basic calculator has factorials, arithmetic operators, radicals and exponents, and transcendental numbers (π and *e*). Based on tests, this calculator is 100% correct, but contact me if there's any bugs and I'll be happy to fix it!
